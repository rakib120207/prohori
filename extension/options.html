Privacy

  • Nothing is read from a page or sent anywhere until you right-click a selection, press Alt+Shift+P, or press Analyze.
  • The text you check is sent only to the server address above, to be scored. This extension does not store it and has no analytics.
  • The default server is the public Prohori demo on Render's free plan: it sleeps when idle and the first check can take up to a minute.
  • For sensitive text, run your own server (see the project README) and put its address here.
